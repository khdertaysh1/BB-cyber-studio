# Blue Dragon branding

The new icon and brand are original Dragon-themed vector graphics, rendered in the native Android launcher and offline start page. The visual concept uses sapphire, cobalt and cyan rather than a generic web template.

| Color token | Value |
| --- | --- |
| Background | `#071426` |
| Surface | `#0B1D36` |
| Card | `#102847` |
| Cobalt | `#187FFF` |
| Electric cyan | `#03CFFF` |
| Text | `#EFF8FF` |
| Muted | `#9EBBD1` |

The welcome page is `app/src/main/assets/start.html`; the native icon is `app/src/main/res/drawable/ic_studio.xml`. Keep user-observed data truthful: Blue Dragon's current WebView Network APIs cannot capture full HTTP(S) response bodies/status/timing.

The GitHub repository slug remains `BB-cyber-studio` so established URLs work; the Android package name `studio.bb.cyber` remains stable for compatible updates.

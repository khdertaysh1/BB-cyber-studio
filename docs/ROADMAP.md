# Roadmap

## 0.1 — usable foundation

- [x] Native mobile navigation, browser and local echo lab
- [x] Request metadata and native HTTP Repeater
- [x] JavaScript console and DOM/style inspection
- [x] Page resource/form map and contextual response-header review
- [x] Termux command handoff and completion results
- [x] Encrypted saved request and clear-data controls
- [x] Build workflow and core HTTP/security regression tests

## 0.2 — interception milestone

- [ ] Prove a real local HTTP(S) proxy on Android ARM64
- [ ] Per-device CA and narrowly scoped browser trust, preserving upstream certificate verification
- [ ] Capture real request/response bodies and status codes, with size bounds
- [ ] Native Intercept controls: forward, drop, edit, timeout and cancellation
- [ ] End-to-end tests for POST, redirects, compressed content and connection failures

## 0.3 — full workspace

- [ ] Authenticated embedded interactive PTY with streaming and cancellation
- [ ] Browser tabs and isolated profiles
- [ ] HAR import/export with explicit secret review
- [ ] WebSocket inspection, richer response comparison and searchable history
- [ ] Arabic localization, tablet layout, persistent UI state
- [ ] Stable signed APK releases and upgrade path

Features are not marked complete until implemented and tested. No AI dependency or paid backend is required for the core product.
